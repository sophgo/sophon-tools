## 应用场景

### 微服务器 SE8 416-BA2-61

微服务器SE8 416-BA2-61是面向大路数视频分析的高密度服务器，搭载算丰第四代智能视觉深度学习处理器BM1684X，大算力、低能耗、小体积，支持混合精度计算，承载丰富的算法应用，灵活应对公安、交通、园区、生产、仓储等大并发业务场景，为行业智慧赋能。

## 超高性能，混合精度

- 支持FP32/FP16/BF16/INT8
- 最大支持416路高清视频智能分析
- 416路 硬件解码1080P@25fps，156路 硬件编码1080P@25fps

## 广泛适配，灵活部署

全面适配主流深度学习框架，工具链SDK成熟易用

- 体积小巧，乐高式拼接上架，支持独立或组合部署
