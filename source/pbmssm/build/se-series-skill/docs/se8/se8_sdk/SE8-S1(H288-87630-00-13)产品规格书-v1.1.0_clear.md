# SE8-S1(H288-87630-00-13)产品规格书-v1.1.0

## SE8-S1

SE8-S1系列是面向大路数视频分析的高密度服务器，搭载算丰第四代智能视觉深度学习处理器BM1684X，X86强劲主控加持，大算力、低能耗、小体积，支持混合精度计算，承载丰富的算法应用，可灵活应对公安、交通、园区、生产、仓储等大并发业务场景，为行业智慧赋能。

## 强劲主控，超高性能，超强解码，增强编码

- 主控节点：X86，3.0GHz，8核16线程，L3 16MB
- 支持FP32/FP16/BF16/INT8
- 最大支持288路高清视频智能分析
- 288路硬件解码1080P@25fps，108路硬件编码1080P@25fps

## 广泛适配，灵活易用

全面适配主流深度学习框架，工具链SDK成熟易用

- 体积小巧，乐高式拼接上架，支持独立或组合部署
