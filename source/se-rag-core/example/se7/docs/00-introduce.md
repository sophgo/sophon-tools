# SE7 产品概览

微服务器 SE7 基于 **BM1684X** 单 SoC 芯片，单节点架构，默认使用 **SoC 模式**（不回答 PCIE 模式问题）。

## 关键信息

- 内核镜像：`/boot/emmcboot.itb`
- 系统：Ubuntu 20.04
- SDK 版本字段：`sophon-mw-soc-*`
- libsophon：v23.09-LTS

## 硬件规格速查

| 项目 | 说明 |
|------|------|
| 芯片 | BM1684X |
| 架构 | 单节点 |
| 算力 | 支持 TPU 深度学习推理 |
| 网络 | 千兆以太网 / Wi-Fi（可选模块）|

## 常见用途

- 边缘 AI 推理服务
- 本地模型部署
- 数据采集与处理
