# SE写卡工具 — 现场使用说明

SE系列设备（SE5 / SE7 / SE9）TF 卡的制作工具。Windows 单文件免安装，双击运行即自动弹 UAC 索要管理员权限（读写物理盘必需）。

> 版本 2.0.0 起由「SETF卡制作工具」更名为 **SE写卡工具**，可执行文件 `sewriter.exe`。
> **2.0.4** 起修掉一个会让卡"看着写好了、插上却不启动"的缺陷：卡上 `fip.bin` 的 8.3 短名
> 曾被写成 `FIP~1.BIN`，而 BL1 只认 `FIP.BIN`（详见第 2 节末「卡上的 8.3 短名」）。
> **2.0.4 之前写的恢复卡请重写。**
> **2.0.5** 修掉「浏览目录…」选中多套了一层刷机包目录时直接报写入失败的问题
> （同一份内容打成 `.zip` 走「浏览文件…」不受影响）。
> **2.0.6** 修掉目录里存在「与刷机包目录同名的嵌套层」时（如 `pkg/pkg/pkg/boot.scr`）
> 内层文件被写到外层同名路径上、写后校验报长度不符的问题。
> **2.1.0** 新增「只格式化 TF 卡」模式，并把主界面改成先选「要做什么」再选数据源；
> 同时修掉大卡（≥ 384 GB）上 FAT32 表建得太小、卡会挂载失败/写坏数据的问题（详见第 7 节）。

## 1. 快速上手

1. 把 `sewriter.exe` 拷到 Windows 机器，**双击**（会弹管理员授权，选"是"）。
2. ① **选择目标设备**：插上读卡器，点「刷新」，在下拉框里选中目标 TF 卡。
   - 系统盘永远不会出现在列表里；SATA/NVMe 等固定盘默认隐藏（勾选「全部」并二次确认才可选）。
3. ② **选择要做什么**（三选一，默认「制作刷机卡」）：
   - **制作刷机卡**（做恢复卡用这个）：卡格式化为 MBR+FAT32，再把数据源里的文件写进去。
     数据源三选一 —— **内置**（程序自带发版文件包，默认）、**浏览文件…**（选发版包
     `se7-recovery-files-<版本>.zip`，或任何 `.img/.img.gz/.txz/.tar.zst`…，按内容自动识别）、
     **浏览目录…**（直接选一个目录，内容即卡根目录该有的东西，不必先打包）。
   - **写入整盘镜像**：把 `.img/.raw/.iso`（或其压缩体）逐字节写到卡上。
   - **只格式化 TF 卡**：只把卡做成 MBR+FAT32，不写入任何文件（见第 6 节）。
4. ③ 勾选「我已核对目标设备，确认覆盖且不可恢复」→**开始写入**（只格式化模式下按钮是「开始格式化」）。
5. 写完后程序自动做三级校验：① 回读逐字节比对 ② 从卡上挂 FAT32 逐文件比对 sha256 ③ 卡根 **8.3 短名**核对（BM1684X 的 BL1 只认短名，见第 2 节末「卡上的 8.3 短名」）。全绿才算完成。
   - 只格式化模式没有文件，只做第 ① 项（回读核对分区表 / BPB / FAT 两份副本）。

> 界面上的「高级选项」默认收起：写入方式自动识别、分区按整卡容量建。只有自动识别不准、
> 或想按内容大小建分区时才需要展开 —— **收起时里面两项不生效**。

## 2. 数据源与写入方式

| 数据源 | 写入方式 | 说明 |
|---|---|---|
| 发版文件包 `.zip` | 文件包 → MBR+FAT32 | **推荐**。只写实际文件，空白区不写；**打开即分析完**（见下方说明） |
| 老文件包 `.txz` | 文件包 → MBR+FAT32 | 同样能写，但**分析很慢**（顺序压缩流，需整条解压，几十秒到几分钟） |
| 目录 | 文件包 → MBR+FAT32 | 与文件包等价，省掉打包步骤 |
| 整卡镜像 `.img/.raw/.iso` | 整盘镜像 | 逐字节写入（含稀疏写入优化） |
| 上述的 gz/xz/bz2/zst/zip/7z/rar/tar 压缩体 | 按内容自动判定 | 压缩包内是单个镜像 → 整盘；是一批文件 → 建卡 |
| 无（「只格式化 TF 卡」模式） | 只建 MBR+FAT32 | 不写入任何文件，见第 6 节 |

### 包格式与速度（重要）

同样是 217 MB 卡内容：

| 格式 | 包大小 | 分析（探测） | 写卡 | 写后文件校验 | 全流程 |
|---|---|---|---|---|---|
| `.zip` | 110 MB | **0.00 s** | 3.5 s | 4.4 s | **8 s** |
| `.txz` | 83 MB | 36.4 s | 36.4 s | 38.8 s | 116 s |

原因：`.txz` 这类顺序压缩流没有索引，要枚举里面有哪些文件就必须把整条流解一遍（Go 的 xz 实现约 5.7 MB/s），而且**写卡、写后校验各自还要再解一遍**；`.zip` 有中央目录，分析时只读目录区，一个字节都不用解压。

> 结论：**优先用 `.zip` 发版包**。手里只有 `.txz` 时也能正常写卡，只是慢（分析阶段进度条会一直跑）。

细节：

- **刷机包根目录自动定位**：压缩包/目录里若多套了一层（如 `sdbootrecoveryfiles/`），工具会按特征文件（`fip.bin` / `boot.scr` / `*.itb`）自动找到刷机包那一层，剥掉外层后再写 —— 保证**落到卡根目录的就是刷机包本身**。存在多个候选目录时不猜，直接报出来让人判断。
- **分区大小**：默认按整卡容量建 FAT32（整张卡都能用）；勾「按内容建分区」则只按文件内容大小建（更快，卡上剩余空间不属于该分区）。
- **目录源**：软链按目标文件处理；FAT32 放不下的条目（设备文件、断链等）跳过并在界面上计数。

### 卡上的 8.3 短名（BL1 只认短名）

FAT32 上每个文件都有两个名字：一个是长名（`fip.bin`，Windows 里看到的就是它），
一个是 8.3 短名（`FIP.BIN`）。**SE7 的 BL1 读卡时只认短名** —— 它用的 FatFs 关掉了长名支持
（`FF_USE_LFN=0`），所以它找 `fip.bin` 时匹配的实际是 `FIP     BIN` 这一串。

这就埋了个坑：如果短名被写成了 `FIP~1.BIN`（本该只在**同名冲突**或**名字超长/含非法字符**时
才用 `~N`），卡上明明有 `fip.bin`，BL1 也找不到 —— 上电串口会打印
`NOTICE: fip not found on SD`，然后回退到板载 SPI flash 启动。

**2.0.4 起**：写卡收尾会自动核对卡根短名，并在日志/摘要里给一行结论：

```
✓ 7 个文件全部校验通过 (216.9 MiB, 耗时 4.6s) ｜ BL1: 卡根 fip.bin 短名 FIP.BIN (BL1 可识别)
```

短名不对会直接判校验失败并弹窗，不会让你拿着一张起不来的卡去现场。
（历史上受影响的是 2.0.4 之前版本写的卡；用旧版写过的卡建议重写。）

## 3. 命令行（无人值守 / 批处理）

```
sewriter.exe                           图形界面（需管理员权限）
sewriter.exe list [--all]              列出磁盘
sewriter.exe info                      查看内置文件包版本信息
sewriter.exe write --disk N [--image <包> | --dir <目录>] [--yes] [--no-verify] [--force]
sewriter.exe format --disk N [--label <卷标>] [--yes] [--no-verify] [--force]
sewriter.exe verify --disk N [--image <包> | --dir <目录>]
sewriter.exe hash [--image <包>]
sewriter.exe repack --image <包> [--out <新程序>] [--skeleton <模板程序>] [--force]
```

示例：

```bat
sewriter.exe write --disk 3 --yes                                   :: 用内置包写磁盘 3
sewriter.exe write --disk 3 --image se7-recovery-files-1.6.0.zip --yes
sewriter.exe write --disk 3 --dir D:\se7-card --yes                 :: 直接拿目录建卡
sewriter.exe write --disk 3 --image pkg.zip --fs-size auto --yes    :: 只按内容大小建分区
sewriter.exe format --disk 3 --yes                                  :: 只格式化 (卷标默认 SE)
sewriter.exe format --disk 3 --label SE7BOOT --yes                  :: 只格式化 + 指定卷标
sewriter.exe verify --disk 3 --image se7-recovery-files-1.6.0.zip   :: 只校验
```

**换包不用重装**：菜单「工具 → 导出自带镜像的新程序…」可以把新文件包追加进程序，生成一个自带新包的 exe（命令行等价于 `repack`）。

## 4. 安全约定

- 系统盘永不出现在可选列表；固定盘判定为"需人工确认"，默认隐藏。
- 写盘前打印目标磁盘型号 / 容量 / 分区表，需勾选确认（CLI 需 `--yes`）。
- 写盘前强制卸载并锁定目标卷（避免"卷被占用 → Access is denied"）。
- 默认写后两级校验，`--no-verify` 可关。

## 5. 兼容性

- **默认交付 32 位版本**：Windows 7 32/64 位、Windows 10/11 均可运行（PE 子系统版本 6.01）。
- 另有 64 位版本 `sewriter-x64.exe`（体积略小、速度略快）。
- 单文件、静态链接，无运行库依赖。

## 6. 只格式化 TF 卡

**什么时候用**：手上这张卡插进 SE7 起不来，串口里 BL1 报 `fip not found on SD` 或者干脆认不出卡 ——
常见原因是卡被别的工具格式化成了 **exFAT / NTFS / GPT**，或者 FAT32 被写坏了。SE7 的 BL1 走
FatFs，**只认 MBR + FAT32**，别的格式一律认不出来。这时不必重新下一份发版包，直接格式化回可用状态。

**怎么用**：② 选「只格式化 TF 卡」→ 填卷标（默认 `SE`）→ ③ 勾确认 → 点「开始格式化」。

**它做了什么**：

- 卡头 1 MiB 清零 → 写 MBR 分区表（1 个分区，起始 LBA 2048 = 1 MiB 对齐，类型 `0x0C` = FAT32 LBA）
  → 建 FAT32 文件系统。**不写入任何文件**，卡根目录是空的。
- 与「制作刷机卡」先建的那张卡是**同一种格式**（同一个建卡函数），两种卡可以互换。
- 只写文件系统元数据 + 文件分配表，卡上空白区一个字节都不擦 —— 快（8 GB 卡几秒），
  但**旧数据不会被抹掉**，只是不再属于任何文件。涉密场合请另行擦除。

**写后校验**：回读核对 MBR 引导签名 / 分区类型与起始位置 / BPB 关键字段 / FAT 两份副本逐字节一致。
没有文件，所以没有文件级校验。

**格式化完怎么放文件**：直接用资源管理器把刷机包内容拷进卡根目录即可。注意两点：

- 卡根必须是 `fip.bin`、`boot.scr` 这些文件本身，**不要多套一层目录**（`sdbootrecoveryfiles/fip.bin`
  这样 BL1 找不到）。
- `fip.bin` 的 8.3 短名必须是 `FIP.BIN`。用资源管理器拷贝一般没问题；拷完不放心可以用
  `sewriter.exe write` 重写一遍，或按 §2 末的说明核对。

## 7. 大卡 / 特定容量上的 FAT32

**2.1.0 修掉一个按容量发作的建 FAT32 缺陷**：算"FAT 表要多少扇区"时用了 32 位整数、
结果又窄化成 16 位、还漏了一项。三种表现：

| 卡容量 | 2.1.0 之前 | 症状 |
|---|---|---|
| 大多数容量 | 正常 | — |
| 14 / 15 / 30 / 60 GB 等 25 档 | FAT 表少算 1~2 个表项 | 卷尾几个簇号超出 FAT 表范围，严格的文件系统驱动会报错 |
| 384 GB ~ 512 GB | FAT 表远小于卷所需（384 GB 算出 32744，实际需要 98280） | 卡**看着格式化成功**，但挂载失败或一写就坏 —— 最难查的那种 |
| ≥ 512 GB | 直接 panic 退出 | 格式化失败 |

**用 2.1.0 之前的版本格式化/写过这些容量的卡，请用 2.1.0 重做一遍。**
回归测试 `TestFAT32GeometryOnLargeCards` 逐 GB 扫 8~48 GB 再补 256/384/512/1024 GB，
每档都卡住"FAT 表必须能寻址卷里每一个数据簇"这个不变量。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 双击无反应 / 提示需要权限 | 程序需要管理员权限；若域策略禁止提权，请用管理员身份的 cmd 运行命令行模式 |
| 列表里没有我的卡 | 点「刷新」；仍没有时确认读卡器被系统识别（磁盘管理里能看到） |
| 提示"卷被占用，Access is denied" | 关掉资源管理器窗口 / 杀毒软件对该盘的扫描后重试（工具已内置强制卸载 + 锁定重试） |
| 写入很慢 | 先看数据源格式：`.zip` 秒开，`.txz`/`.tar.zst` 要整条解压（见 §2 速度表）。写后两级校验本身也要读一遍，急用可加 `--no-verify`（不推荐） |
| 报"包内没有找到刷机包" | 该压缩包内容不是卡根目录该有的东西；确认包内有 `fip.bin` / `boot.scr` / `*.itb` |
| 卡插上 SE7 不启动（`fip not found on SD`） | 卡的格式不对或 `fip.bin` 短名不对：先用「只格式化 TF 卡」重做一遍（§6），再把文件拷回去；拷完仍不行就用「制作刷机卡」整卡重写 |
| 「写入方式」「按内容建分区」找不到 | 它们在「高级选项」里，默认收起（默认就是推荐值：自动识别 + 按整卡建分区） |
